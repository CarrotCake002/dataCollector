# Robopol

Robopol is a project I developped in 5 months during my internship at ShBarcelona.

This tool is a web crawler/scraper which allows you to collect data from any page's HTML code.
The particularity of Robopol is that it can navigate a page  

## Usage

You can use the tool freely by clicking [here](https://dev.nodejs.serveishabitatge.com/).
